🧠 General Knowledge Quiz Game
This is a command-line Python quiz game that tests your general knowledge. It loads questions from a CSV file and presents them with multiple-choice answers.

📁 Project Structure

├── quiz.py                         # The main Python script
├── general_knowledge_questions.csv # CSV file containing quiz questions
├── README.md                       # This file

📋 CSV Format
Make sure your CSV file is formatted like this (with headers):

question,option1,option2,option3,answer
What is the capital of France?,Paris,Lyon,Marseille,Paris
Which planet is known as the Red Planet?,Mars,Venus,Jupiter,Mars
Who wrote 'Romeo and Juliet'?,Shakespeare,Dickens,Tolkien,Shakespeare

The answer field must match one of the options exactly.
